# Student Task & Progress Tracker

## 📌 Overview

This is a Java-based console application that helps users manage daily tasks efficiently. Users can add, delete, update, and track tasks with priority and deadlines.

## 🚀 Features

* Add new tasks
* View all tasks
* Mark tasks as completed
* Delete tasks
* Sort tasks by priority
* Filter tasks (Pending / Completed)
* Persistent storage using file handling

## 🛠 Tech Stack

* Java
* OOP Concepts
* Collections (ArrayList)
* File I/O (BufferedReader, BufferedWriter)

## ▶️ How to Run

1. Clone the repository
2. Compile all Java files
3. Run `Main.java`
4. Follow menu instructions

## 📂 Project Structure

* model → Task class
* util → File handling logic
* main → Application entry point
